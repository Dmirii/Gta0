# Публикация VAULT RUNNER в RuStore (инструкция Этапа 3)

Android-проект уже настроен на единый исходный код с веб-версией: при каждой сборке Gradle автоматически копирует свежие `index.html`, `privacy.html`, `css/`, `js/` и `assets/` из корня репозитория внутрь APK.

- **Package Name:** `ru.dimaa.vaultrunner`
- **Минимальный Android:** 7.0 (API 24) · **Целевой Android:** 15 (API 35)
- **Офлайн-режим:** 100% локальные ассеты (`WebViewAssetLoader`), разрешение только `VIBRATE`.
- **Иконка для карточки RuStore:** `assets/icon-512.png` (`512×512` PNG)
- **Политика конфиденциальности:** `https://dmirii.github.io/Gta0/privacy.html`

---

## Шаг 1. Протестировать Debug APK на телефоне (уже можно сейчас!)

1. Откройте вкладку **Actions** в репозитории GitHub → **Build Android APK (RuStore)**.
2. Скачайте артефакт `vault-runner-v1.0.0-debug-test-apk`, распакуйте и установите `.apk` на свой Android-смартфон.
3. Проверьте игру в авиарежиме: управление, звук/музыку, паузу по кнопке «Назад», сворачивание и сохранение прогресса.

> ⚠️ `debug-test-apk` годится только для проверки на телефоне — **в RuStore его загружать нельзя**, для RuStore нужен подписанный `release` APK (Шаг 2).

---

## Шаг 2. Создать ваш личный релизный ключ (один раз навсегда)

Выполните на своём компьютере (понадобится установленная Java / `keytool`, она входит в JDK или Android Studio):

```bash
keytool -genkeypair -v \
  -keystore vault-runner-release.keystore \
  -alias vaultrunner \
  -keyalg RSA -keysize 2048 -validity 10000
```

Придумайте и **надёжно сохраните** пароль хранилища (`keystore password`) и пароль ключа (`key password`).
> 🔐 **Важно:** сохраните файл `vault-runner-release.keystore` и пароли в надёжном месте (например, в менеджере паролей и на флешке). Все будущие обновления игры в RuStore должны быть подписаны **этим же ключом**. Никогда не загружайте файл ключа в Git!

Преобразуйте ключ в строку Base64 (чтобы добавить в GitHub Secrets):
- **macOS / Linux:**
  ```bash
  base64 -w 0 vault-runner-release.keystore > keystore.b64
  # (на macOS: base64 -i vault-runner-release.keystore | tr -d '\n' > keystore.b64)
  ```
- **Windows (PowerShell):**
  ```powershell
  [Convert]::ToBase64String([IO.File]::ReadAllBytes("vault-runner-release.keystore")) | Set-Content keystore.b64
  ```

## Шаг 3. Добавить 4 секрета в GitHub и собрать подписанный Release APK

1. Откройте на GitHub: **Settings → Secrets and variables → Actions → New repository secret**.
2. Создайте 4 секрета:
   - `RUSTORE_KEYSTORE_BASE64` — содержимое файла `keystore.b64` (одной строкой)
   - `RUSTORE_KEYSTORE_PASSWORD` — пароль хранилища
   - `RUSTORE_KEY_ALIAS` — `vaultrunner`
   - `RUSTORE_KEY_PASSWORD` — пароль ключа
3. Перейдите в **Actions → Build Android APK (RuStore) → Run workflow**:
   - для первого релиза оставьте `version_code = 1`, `version_name = 1.0.0` (для каждого следующего обновления увеличивайте `version_code`: `2`, `3`, ...).
4. Через ~2–3 минуты скачайте артефакт **`vault-runner-v1.0.0-release-apk`** — внутри лежит готовый подписанный `app-release.apk`!

---

## Шаг 4. Заполнить карточку и отправить на модерацию в RuStore

В [RuStore Консоли](https://console.rustore.ru/) нажмите **«Добавить приложение» → Android → Универсальное**:

- **Название:** `VAULT RUNNER`
- **Категория:** `Игры` → `Экшен` (или `Аркады`)
- **Возрастной рейтинг:** `12+`
- **Иконка:** загрузите `assets/icon-512.png`
- **Политика конфиденциальности:** `https://dmirii.github.io/Gta0/privacy.html`
- **Контакт поддержки:** `dimaa@dimaa.ru`
- **Скриншоты:** снимите **3–5 скриншотов** на телефоне (реальный геймплей, ночные перестрелки, Гараж с апгрейдами, контракты) без верхней системной строки Android.

### Готовые тексты для карточки (можно править по вкусу)

**Краткое описание (до 80 символов):**
> 2.5D кибер-экшен на авто по ночному мегаполису: гараж, ракеты, слоу-мо и чиптюн.

**Полное описание:**
> VAULT RUNNER — динамичный 2.5D-экшен с видом сверху в сеттинге ночного постапокалиптического кибер-мегаполиса.
>
> Гоняйте по разрушенным проспектам, уходите от радиационных кратеров и цифровых разломов, выполняйте контракты и сражайтесь с рейдерами, броневиками, Агентами и тяжёлыми Карателями Системы.
>
> ОСОБЕННОСТИ ИГРЫ:
> • 5 классов боевых машин в Гараже — от маневренного SCOUT BUGGY до 6-колёсного WAR RIG MK-IV и стелс-болида CYBER PHANTOM.
> • Визуальные апгрейды прямо на машине: сдвоенные пулемёты и плазменные турели, самонаводящиеся ракеты, шипастый таран, бронеборта, турбо-нитро и Ядро Перегрузки.
> • Цифровой Фокус (слоу-мо): замедляйте время в критические моменты, чтобы уходить от ракет и прицельно бить врагов.
> • Процедурный звук: живой синтез двигателя для каждого класса кузова, переключение передач, визг шин и драйвовый чиптюн-саундтрек в стиле Keygen.
> • Прогрессивная сложность: враги усиливаются от MK-I до MK-V вместе с вашим Гаражом.
> • 100% офлайн, без рекламы, без регистрации и без сбора персональных данных — прогресс хранится локально на вашем устройстве.
